# React example

This example shows how to call the LedgerService from a React/TypeScript app
using `@connectrpc/connect-web` and the auto-generated TypeScript client.

## Codegen

The TypeScript types and Connect client live under `examples/react/src/gen/`
and are regenerated by `buf generate` from the root of the repo.

## Install

```
cd examples/react
npm install
```

## Usage

```ts
import { fetchBalance } from "./src/fetchBalance";

const resp = await fetchBalance("t1", "user:1:cash_available:USD", "USD");
console.log(resp.balance?.normalized);
```

## Typecheck

```
npm run typecheck
```

The example does not bundle a build target — copy the source files into
your own React app or wrap them in your bundler of choice.
